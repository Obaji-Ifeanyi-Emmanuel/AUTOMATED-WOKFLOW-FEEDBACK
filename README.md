

In this project, I built an automated workflow to process user feedback efficiently. The system begins with a form submission trigger that captures incoming user responses in real-time. Once the feedback is collected, it is sent to an AI model for analysis. The AI carefully reads the text to identify key positive remarks and specific areas for improvement. After the AI completes this analysis, the structured result is automatically organized and logged into a Google Sheet. This automation streamlines data management by removing the need for manual data entry and summarization.
